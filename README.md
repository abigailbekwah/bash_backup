# bash-backup-tools

A backup tools for all your documents, files and any other thing in your laptop to avoid some incidents that can happen with the laptop or you hard drive.

## Problem_Statement​

A laptop gets stolen in a taxi. A hard drive dies the night before a presentation. Every developer has a story about lost work. Today you build backup.sh, a professional-grade tool that creates compressed, timestamped backups and cleans up old ones automatically.

## 📌 Project Goals​

- safe space and stay organised
- Cleans up old backup authomatically
- Prevent errors and crashes
- Keep your files and document safe
